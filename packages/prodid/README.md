# prodid

The same library as [`@prodid/core`](https://www.npmjs.com/package/@prodid/core), under the short
name: every export of `@prodid/core`, at the same version.

```sh
npm i prodid
```

```ts
import { validateFeed } from 'prodid'
```

The specification, the schemas and the conformance vectors are in
[`@prodid/spec`](https://www.npmjs.com/package/@prodid/spec) and at <https://prodid.org/spec>.
